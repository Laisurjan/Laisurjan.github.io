# Laisurjan 教學創新作品庫

教師向的互動教材與教學工具展示站，發布於 `https://laisurjan.github.io/`。

## 收錄原則

- 收錄可供教師理解、試用或延伸的公開網頁。
- 依教學使用情境分類，不依程式語言分類。
- `money`、`hlbhteacher`、`teacher` 專案不收錄，也不進入自動詢問流程（例外：`teacher/ig/` 留言區教材頁、`teacher/jin/` 春秋棋局簡報、`teacher/jin/talk/` 說話的棋局、`teacher/scales/` 年關遊戲、`teacher/redbuilding/` 大觀園理家記、`teacher/gpt-talk/` 免費版 GPT 做教學遊戲經本人同意收錄；`teacher` 根目錄的行政人數統計頁仍不收錄）。
- 新專案不會自動加入：每日檢查流程會先開 Issue 詢問本人，確認後才更新展示站。

## 更新作品

作品資料集中在 `app.js` 的 `projects` 陣列。新增一筆作品、確認分類與說明後提交，即會由 GitHub Pages 更新。

可用分類：

- `tools`：教學工具
- `language`：語文人文
- `cross`：跨域素養（含跨域探究、生涯與社會情緒素養）

## 本機預覽

這是純靜態網站，可直接開啟 `index.html`，或使用任何靜態檔案伺服器預覽。
